# Tabs Pin documentation

Tabs Pin is a Manifest V3 extension for Firefox and Chrome that saves the sites you keep pinned,
sorts them into categories and reopens them as pinned tabs without duplicates. Everything is stored
locally: no account, no server, no tracking.

The overview, installation, usage and privacy notes are in the [README](../README.md).
